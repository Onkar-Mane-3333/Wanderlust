# Wanderlust

Find Your Perfect Stay Anywhere.
Developed a full-stack Airbnb-style web application that allows users to explore, list, and review accommodations. Implemented user
authentication with Passport.js, secure session management, and RESTful CRUD operations for listings and reviews. Utilized MongoDB
and Mongoose for database management, Express.js for routing and middleware, and EJS with Bootstrap for dynamic and responsive
UI rendering. Integrated flash messages and custom error handling for enhanced user experience and reliability.

Tech Stack
• Node.js  
• Express.js  
• EJS (Templating)  
• CSS, HTML,JavaScript  
• MongoDB

Feature:
It allows users to register, log in, create travel listings, view listings, add reviews, and manage their own content

How to Run
1. git clone https://github.com/Onkar-Mane-3333/Wanderlust
2. cd Wanderlust
3. npm install
4. npm start
5. Open http://localhost:8080/Listings in your browser

Note:
Make sure Node.js and npm are installed on your system before running the project.
